# 🗺️ Country Explorer Kids

> *Explore the world, one country at a time!*

A fun, interactive geography app for children aged 4–6. Hop aboard Flutter the butterfly's magical train and explore 50 countries — learning flags, capital cities, continents, and amazing fun facts along the way!

![Country Explorer Kids](https://img.shields.io/badge/Age-4--6%20years-brightgreen) ![Countries](https://img.shields.io/badge/Countries-50-blue) ![License](https://img.shields.io/badge/License-MIT-yellow)

---

## ✨ Features

- 🌍 **50 countries** across 6 continents
- 🚩 **Flags** — see and learn each country's flag
- 🏙️ **Capital cities** — with real landmark photos
- 📸 **Real photos** — famous sights for every country
- 🎉 **Fun facts** — AI-powered wow facts for kids
- 📖 **Passport system** — collect stamps as you explore
- 💎 **Continent gems** — unlock gems by completing regions
- 🚂 **Flutter the butterfly** — your friendly train conductor guide
- 📱 **Mobile-friendly** — works great on phones and tablets

## 🏗️ Setup & Deployment

### Option 1 — GitHub Pages (Recommended, Free)

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch → main**
4. Your app is live at `https://yourusername.github.io/country-explorer-kids`

### Option 2 — Run Locally

Just open `index.html` in any modern browser. No build step needed!

> **Note:** The AI fun facts feature requires an internet connection to reach the Anthropic API.

### Option 3 — Android App (Play Store)

Wrap as an Android WebView app using any of these free tools:
- [WebIntoApp](https://webintoapp.com) — paste your GitHub Pages URL → get APK in 2 minutes
- [AppMySite](https://www.appmysite.com) — with Play Store submission help
- [Median.co](https://median.co) — more polished wrapper

## 🎮 How to Play

1. **Browse the Map** — tap any country to start exploring
2. **Meet Flutter** — your butterfly guide flies you there by train 🚂
3. **Learn step by step:**
   - 📸 See a famous landmark photo
   - 🚩 Learn the flag
   - 🏙️ Discover the capital city
   - 🌍 Find out which continent it's on
   - 🤩 Get an amazing wow fact
4. **Collect your stamp** — added to your passport!
5. **Unlock continent gems** — complete all countries in a region
6. **Become a World Explorer Champion** — visit all 50 countries! 👑
